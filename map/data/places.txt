# places
#
# The experience tour: where each stop is, and what it meant. Read in order,
# oldest first — the tour is a path through time as much as through Gujarat.
#
# Same grammar as the rest of this project: two spaces starts a key, four or
# more continues the previous value.
#
#   at       LATITUDE, LONGITUDE — in that order.
#
#            Note this is the opposite of `.tmap`, which is lon/lat. It is
#            lat/lon here because that is the order every map website, every
#            phone, and exp.md itself uses, and this file is written by hand
#            from those. The parser rejects an out-of-range pair rather than
#            quietly drawing the wrong hemisphere.
#
#   zoom     where the flight stops.
#
#            Around 14.5, which is wider than it sounds like it should be. The
#            basemap has no building footprints outside Mumbai, so street zoom
#            over Ahmedabad is half a dozen roads on an empty plate — accurate,
#            and nothing to look at. A little further back the road network and
#            the neighbourhood labels arrive together, and *that* is what reads
#            as a place. Zoom to the data you have, not to the data you meant.
#   tilt     degrees the camera leans on arrival, after it has stopped moving.
#            The lean is the last thing that happens, so the place rises into
#            three dimensions once you are already looking at it.
#   bearing  degrees clockwise from north-up. Varied between stops so the
#            arrival does not feel stamped from one template.
#   note     what it meant. Not what the building is — what happened there.
#
# Content is from experience/exp.md, which is the source of record.
